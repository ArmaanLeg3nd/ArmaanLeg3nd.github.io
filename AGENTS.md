# Website editing instructions

Before changing the concise OSCP reference at `/oscp/nstsec/`, read [OSCP_NOTES_BLUEPRINT.md](OSCP_NOTES_BLUEPRINT.md) and the adapted-notes section of [CONTENT_GUIDE.md](CONTENT_GUIDE.md). Preserve the clean eight-track structure and existing content ownership. Put tool choices, setup and usage in the owning procedure; Extra tools to obtain is only an aggregation of those pages' actual extra-tool links. Avoid parallel reference/comparison layers and duplicated procedures. Update the blueprint in the same change when the structure intentionally changes.

For wrapper replacements, apply the blueprint's "Replacing wrappers with direct tool use" rule: choose task-beneficial options and concise direct invocations, preserve useful upstream orchestration and unique collector functionality, and avoid copying wrapper implementation details into the notes.

The reviewed Markdown in the OSCP vault is the authoring source; snapshots are generated. Follow the existing validation and verified Pages publishing workflow in CONTENT_GUIDE.md. Keep private course and target evidence out of this repository.
