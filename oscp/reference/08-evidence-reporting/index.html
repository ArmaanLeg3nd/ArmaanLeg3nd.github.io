      9.8.0 Stage 08: Evidence and Reporting

      ← Main index | Evidence cheatsheet | Master Notes | Strategy map | Study methods: Complete attacks and retain reproducible evidence

      Purpose: control an unfamiliar attack as an evidence-backed state machine, preserve every access/privilege transition and produce a compliant report without reconstructing commands from memory.

      TaskOpen
      Select paths, recover from dead ends and capture report-ready evidenceIntegrated attack tracking and evidence

      Exit condition: each objective has an ordered reproduction path, host/identity proof, required screenshots/output, exploit-source/modification record and a reviewed report artifact.
