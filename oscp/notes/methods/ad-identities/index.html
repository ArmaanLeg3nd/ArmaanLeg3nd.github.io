    6.3.11 Gain a more useful domain identity

    Strategy map | Master Notes | Operational index | Cheatsheets

    Choose a credential source or object transition by its prerequisites. Track the exact account, credential type and compatible service after every transition. Conditional AD CS/delegation/GPO branches require their own complete enabling chain.

    Speedrun blocks: 11; credential classification in 5. Documented methods: 18.

    Examples are hypothetical study material. Apply commands only to an assigned scope during the later practice phase. A method is enabled by its prerequisites; its presence here does not establish a vulnerability or practical mastery.

    6.3.11.1 First pass: tools and findings

    Use the branch matching the current host, identity and observed result. Tool output supplies leads; the linked procedure verifies and uses the exact condition.

    6.3.11.1.1 Inspect the tickets/material already available

    Use the current identity and ticket cache before attempting credential collection or ticket construction.

    klist
    • If A valid service-scoped ticket: Check service principal, expiry and the matching client. → Classify tickets and use a compatible cache.
    • If A privileged local token and an accessible credential source: Check protection and exact source prerequisites before selecting a collector. → Obtain accessible live logon-session credential material.
    • Otherwise: No useful ticket/source: inspect account configuration and object rights with the available domain identity. → Enumerate directory objects with native, LDAP and PowerView approaches.

    6.3.11.1.2 Choose AS-REP or SPN roasting from account evidence

    Use this branch only for a confirmed preauthentication-disabled account; ordinary SPN accounts use a different request.

    impacket-GetNPUsers 'DOMAIN/USER' -no-pass -dc-ip DC_IP
    • If A valid AS-REP response for the known account: Use the type-specific offline recovery path. → Request AS-REP material for an account without preauthentication.
    • If A normal service account with an SPN: Request the matching service ticket in an authenticated context. → Request a selected service ticket for offline service-account recovery.
    • Otherwise: The account requires preauthentication: stop this path and inspect SPNs or effective object rights. → Validate effective directory-object control.

    6.3.11.1.3 Resolve an ACL edge to its concrete operation

    Use the exact trustee, target class, GUID and inheritance/deny behavior, not the graph label alone.

    Get-DomainObjectAcl -Identity TARGET_OBJECT -ResolveGUIDs
    • If Effective password-reset right on the intended user: Confirm account state and the effect of changing its password. → Reset a target account password through a validated directory right.
    • If Effective write to a useful group's member attribute: Confirm the group effect and refresh the resulting token/logon context. → Add a controlled identity to a group through effective membership rights.
    • If WriteOwner/WriteDacl on the target object: Preserve original state and validate each intermediate right. → Convert ownership or DACL control into a narrower useful right.
    • Otherwise: The right is not effective for the controlled principal: discard that edge and inspect another verified relationship. → Enumerate directory objects with native, LDAP and PowerView approaches.

    6.3.11.2 Discovery workflow

    Start from a mapped object/right, an available ticket, or a host whose current privilege may expose a credential source.

    Follow these observations into a method; the detailed recognition routes below show synthetic output and the checks still needed.

    1. Inspect existing tickets and host privilege/protection before invasive collection: Inventory, convert and import tickets in the correct logon context; Obtain accessible live logon-session credential material.
    2. Choose matched local credential sources and classify what each produces: Extract local account hashes from matched SAM and SYSTEM; Extract LSA secrets and cached-domain verifiers; Use Credential Manager and DPAPI with the protecting context; Parse an offline domain database or select a justified remote collection path.
    3. Discover the actual account flag or SPN before choosing a roast path: Request AS-REP material for an account without preauthentication; Request a selected service ticket for offline service-account recovery; Create a temporary SPN through an effective object right.
    4. Resolve the exact ACE and object before password, group, DACL or replication transitions: Reset a target account password through a validated directory right; Add a controlled identity to a group through effective membership rights; Convert ownership or DACL control into a narrower useful right; Use validated directory replication rights for bounded credential proof.
    5. Expand certificate, delegation or GPO paths only when their specific configuration evidence exists: Conditional: validate an AD CS enrollment-to-authentication path; Conditional: use a validated delegation or RBCD relationship; Conditional: trace GPO control to privileged policy consumption.

    PowerView examples require a reviewed compatible script in the current authenticated directory context. Check the loaded copy rather than mixing legacy/fork parameter names; the directory-mapping entry includes native, ADSI and LDAP alternatives.

    Import-Module .\PowerView.ps1
Get-Command -Module PowerView

    Decision rule: an observed clue opens a candidate. Choose it only after the missing conditions are verified; a failed check rules out that context, while unavailable evidence stays inconclusive.

    6.3.11.3 Method families

    • Host credential sources: Obtain accessible live logon-session credential material, Extract local account hashes from matched SAM and SYSTEM, Extract LSA secrets and cached-domain verifiers, Use Credential Manager and DPAPI with the protecting context, Parse an offline domain database or select a justified remote collection path.
    • Password-derived ticket recovery: Request AS-REP material for an account without preauthentication, Request a selected service ticket for offline service-account recovery, Create a temporary SPN through an effective object right.
