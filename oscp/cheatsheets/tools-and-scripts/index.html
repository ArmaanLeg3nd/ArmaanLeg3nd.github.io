    10.16 Tools and scripts by task

    Cheatsheet index | Operational index

    Choose a task, then use its complete commands and conditions. Tool links open the upstream source/documentation; they do not install anything.

    10.16.1 Quick lookup

    Tool / scriptChoose it forProcedure
    NmapFull TCP coverage; identify applications on the ports found.Discover TCP ports with SYN or connect scans
    Nmap UDPKeep UDP results and ambiguous silence separate from TCP.Probe UDP and resolve ambiguous silence
    smbclientList shares, then read files in the accepted identity.Enumerate SMB/RPC shares, files and identities
    SMBMapMap share rights and retrieve one useful file.Enumerate SMB/RPC shares, files and identities
    enum4linux-ngCollect SMB/RPC candidates with anonymous or known credentials.Enumerate SMB/RPC shares, files and identities
    snmpwalkQuery an observed community/version for configuration leads.Extract configuration and process information through SNMP
    digResolve names and test authorized zone-transfer conditions.Expand names through DNS records and zone transfers
    impacket-mssqlclientInspect SQL Server login, grants and enabled operations.Use SQL Server rights, impersonation and command facilities
    curlReplay the real host, method, cookie and input.Establish scheme, host, redirects and request state
    GobusterDiscover paths after measuring a missing-path response.Discover directories and files with controlled response filtering
    ffufFuzz one boundary in a valid request; preserve its session.Map parameters, API methods, objects and writable properties
    Burp SuiteCapture and compare normal requests before modifying inputs.Map functions, roles and normal requests manually
    WPScanUse only after confirming WordPress and relevant components.Use WordPress component evidence and authorized administration features
    curl request testsProve the command/parser effect before choosing a session.Prove visible or blind operating-system command injection
    HashcatSelect the identified artifact format and feasible candidate strategy.Recover passwords with feasible dictionary, rule and mask attacks
    John the RipperExtract a supported verifier, recover offline, then validate access.Recover passwords with feasible dictionary, rule and mask attacks
    RunasCsUse known plaintext credentials from an existing Windows shell.Validate known passwords and context-specific reuse
    SearchSploitFind and inspect a PoC matching the exact feature/configuration.Match a public exploit to the actual component and configuration
    Python venvSeparate local runtime/dependency errors from target rejection.Audit a PoC and reproduce its interpreter/dependency environment
    GCCMatch process architecture, ABI and required libraries.Compile and minimally adapt an existing native or memory-corruption PoC
    SCPMove files when authenticated SSH is the reachable channel.Copy files through an authenticated SSH service
    Python HTTP serverTransfer a reviewed artifact over a reachable HTTP leg.Transfer over HTTP using Linux or Windows clients
    PTY / sttyStabilize an existing command session; retain the original channel.Repair a limited Linux terminal
    LinPEASEarly Linux candidate collection, followed by exact-object checks.Use enumeration tools to generate manually testable candidates
    pspyObserve transient privileged consumers and their real commands.Control a script, binary or configuration consumed by a privileged job/service
    GTFOBinsMatch the exact binary, rule and privilege-preserving mode.Use an allowed sudo operation to cross a privilege boundary
    getcap / capabilitiesConnect an effective file capability to an available operation.Use a file capability that enables a specific privileged operation
    winPEASEarly Windows candidate collection; inspect out.txt.Turn automated Windows findings into manually verified candidates
    SeatbeltChoose a focused system or current-user survey.Turn automated Windows findings into manually verified candidates
    PrivescCheckCheck permissions in the current token, with readable reports.Turn automated Windows findings into manually verified candidates
    LaZagneRecover supported application stores in the accessible user context.Recover Windows application, history and stored-credential artifacts
    SharpHound / BloodHound CECollect compatible graph data and validate the useful edge.Collect focused BloodHound data and validate an attack path
    NetExecValidate domain identity and service-specific authorization.Establish domain identity, DC, DNS, time and route
    PowerViewInspect directory objects/rights from the current Windows context.Enumerate directory objects with native, LDAP and PowerView approaches
    Impacket Kerberos toolsUse the matching identity, SPN and ticket-request prerequisites.Request a selected service ticket for offline service-account recovery
    RubeusInventory ticket contexts before using a selected ticket.Inventory, convert and import tickets in the correct logon context
    CertipyInspect AD CS prerequisites before a certificate-based transition.Conditional: validate an AD CS enrollment-to-authentication path
    Evil-WinRMUse when the accepted identity has WinRM authorization.Use WinRM, WinRS or PowerShell remoting
    Impacket WMIUse a permitted WMI/RPC path with the matching authentication material.Execute through WMI or native CIM over DCOM
    FreeRDPCheck remote interactive rights and preserve the current session.Obtain an authorized RDP interactive session
    SSH forwardsChoose the listening side and destination leg explicitly.Forward a selected service through an SSH client-side listener
    ChiselUse a reverse transport when the pivot can reach your listener.Use a reverse Chisel SOCKS or fixed TCP tunnel
    Ligolo-ngRoute only the intended internal prefixes through the working agent.Route a selected internal subnet through Ligolo-ng
    ProxyChains-NGUse compatible TCP clients through a verified SOCKS listener.Use ProxyChains, native SOCKS clients and SSH jump paths appropriately
    Metasploit handlerMatch payload transport, architecture and listener; inspect framework limits.Pair staged payloads with the correct handler and session lifecycle
    PowerShellDistinguish parsing, policy, runtime and process architecture failures.Distinguish PowerShell policy, language mode and protected execution layers
    file / readelfCheck format and ABI before changing a payload.Match an artifact to its executable consumer and runtime
    Native identity proofRecord host/identity and the exact capability change.Capture state-transition, proof and exploit-adaptation evidence

    The command-first organization and gap review were informed by 0xsyr0/OSCP. Commands and interpretations here are maintained against the linked upstream documentation and our owning procedures. Full exploit files remain at their upstream locations; no third-party repository is mirrored here.
